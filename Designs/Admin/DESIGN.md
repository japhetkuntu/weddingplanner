## Brand & Style

The visual theme of the platform, shared across Admin, Client, and Public portals, is directly extracted from the live ovutor.com site. It uses a warm off-white/cream background (#FAF9F8), a primary accent of brick red (#C1281B), and near-black charcoal (#1E1E1E) for text. Typography features an elegant, high-contrast serif for headlines and a clean sans-serif for body copy and UI text. Buttons are either solid red with white text, red outline with red text, or solid charcoal with white text, all with square corners. The overall aesthetic emphasizes generous whitespace, editorial photography, and a calm, warm, and understated tone.

## Usage

Use this file only as a public design summary for downstream agents. It intentionally omits internal workspace state, prompts, diagnostics, and generation plans.
